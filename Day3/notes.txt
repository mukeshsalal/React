Callback in setFunc or Update function

1> If new value state is depend in old state then we will update by callback 

// Do like this
function increaseCount(){
    setCount((oldVal)=>{
        return oldVal + 1;

    });
    setCount((oldVal)=>{
       return oldVal+1;
    })
}


// Not  like this
function increaseCount(){
    setCount(oldVal+1);
    setCount(oldVal+1);
}


2> If new value state is not depend  in old state then we will update normally
